# machine-room-downloads
Official downloads for Machine Room — a free drum machine VST3 with 16 classic machines.

**[Download the latest version](https://github.com/savicreations/machine-room-downloads/releases/latest)** · Windows 10/11, VST3 · Try it in your browser at [machineroom.netlify.app](https://machineroom.netlify.app)

## Install
1. Unzip the download.
2. Copy the whole `Machine Room.vst3` folder into `C:\Program Files\Common Files\VST3`.
3. Rescan plugins in your DAW (FL Studio, Ableton Live or any VST3 host) and load Machine Room as an instrument.

No internet needed: the sounds are inside the plugin.
